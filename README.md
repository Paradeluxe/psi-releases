# PSI installers

Public Windows Setup files only. **Source is not here.**

Lab PCs: download the latest `PSI-Setup-x.y.z.exe` from [Releases](https://github.com/Paradeluxe/psi-releases/releases).

Maintainers: keep the private source repo private. After `npm run dist:win`, attach `PSI-Setup-*.exe` to a Release **here** (tag `vX.Y.Z`, same version as `desktop/package.json`). Do not upload source, wheels trees, or the private tree.
